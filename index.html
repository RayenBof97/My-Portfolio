Experience

Research Intern – AI & Digital Predistortion

IEMN CNRS (in collaboration with Nokia & CEA-Leti) September 2025 - January 2026 (5 months)

During my research internship at IEMN CNRS, working alongside Nokia and CEA-Leti on 5G/6G systems, I modeled and linearized RF power amplifiers using RNN-based models (LSTM/GRU) on signals up to 18.7 GHz / 112 MHz. I compared predistortion methods such as Memory Polynomial and GMP against AI-based models to identify the optimal approach, and quantified the spectral impact of these predistortion models on adjacent channel emissions through an analysis of over 168,000 samples, validated by the IEMN/Nokia team.

Embedded Systems and Signal Processing Internship

Shanon Technologies July - August 2025 (2 months)

At Shanon Technologies, I designed a modular C/C++ architecture for Kalman filtering (KF/EKF/UKF), built to be reusable on the Papaya VL board. I developed robust RLS algorithms for real-time adaptive estimation on noisy and ill-conditioned systems, reducing parameter estimation error by 38% (from 0.21 to 0.13). I worked in an Agile/Scrum environment, keeping the deliverable reliable through weekly code reviews and technical documentation.

Embedded Software and Control Internship

Visteon Corporation July - August 2024 (1 month)

During my internship at Visteon, I worked on industrial communication protocols, particularly Modbus over RS485, and diagnosed the SMEMA protocol between production equipment. I also explored Fuzzy Logic Control and the Kalman Filter for state estimation. Remote Control System for an Autonomous Differential-Wheeled Robot

May 2024 - June 2024

This project focuses on developing a remote control system using an intuitive graphical user interface (GUI) to interact with a differential wheeled robot. The system employs an ESP32 microcontroller with integrated Wi-Fi for communication, enabling real-time control and monitoring from any location. A nested-loop controller is implemented to regulate both the position and velocity of the robot. The communication between the interface and the system is established via the MQTT protocol, allowing for efficient data exchange over local and wide-area networks. The project demonstrates the adaptability of the interface, making it applicable to various industrial control systems, such as temperature or level regulation.
